What teams build with personalization signals

Personalization is not just language and currency. It is choosing the right flow for the user, with the right friction, at the right time. True Geo IP provides a single lookup endpoint that returns location, network context, and traffic quality signals.

Localization that ships fast

Default to the right country, timezone, and currency, while keeping overrides and consent in your control.

Region-aware routing

Send users to the nearest region, pick the closest edge, or choose the best fallback when latency matters.

Smarter onboarding flows

Reduce abandonment by adapting verification steps when traffic quality or network signals look unusual.

One lookup. Multiple signals.

True Geo IP returns structured fields you can use immediately, plus consistent defaults for safe UI rendering. You control how much you use, and where you apply it.

Signals commonly used for personalization

Geo context Country, region, city, timezone, and continent for localized defaults and regional routing.
Network identity ASN and organization fields for enterprise routing, analytics segmentation, and B2B experiences.
Traffic quality VPN and datacenter detection, crawler hints, and a threat level field for step-up UX decisions.
Commerce helpers Currency codes and country metadata useful for default checkout experiences.

Implementation in minutes

Call the lookup endpoint from your server (recommended) or client-side. Add an API key to associate usage with your project and unlock plan limits.

cURLserver-side
curl -s 'https://truegeoip.com/api/check?ip=8.8.8.8' \
  -H 'X-API-Key: YOUR_KEY'
JavaScriptfetch
fetch('https://truegeoip.com/api/check?ip=8.8.8.8', {
  headers: { 'X-API-Key': 'YOUR_KEY' }
}).then(r => r.json()).then(console.log);
Can I use it only for defaults (and not enforcement)?

Yes. Many teams use True Geo IP to pre-fill country/timezone and improve routing, while still letting users override.

Does this require cookies?

No. IP intelligence can work without cookies. If you also use first-party identifiers, keep privacy and consent aligned with your policy.

Is the response stable across IPv4 and IPv6?

Yes. True Geo IP is built for IPv4 and IPv6 coverage, and normalizes output fields so your integration stays consistent.
