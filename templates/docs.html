API Documentation

Complete reference for the TrueGeoIP API.

Authentication

Live lookup is public. Analytics ingest uses a separate API key.

Analytics ingest API: X-API-Key: YOUR_ANALYTICS_KEY

Endpoints

Get IP Info

GET /api/check?ip={ip_address}

Returns detailed geolocation and ASN data for a specific IP.

curl "https://api.truegeoip.com/api/check?ip=8.8.8.8"

Response

{ "ip": "8.8.8.8", "country_code": "US", "country_name": "United States", "city": "Mountain View", "asn": 15169, "org": "Google LLC", "user_type": "Datacenter" }
