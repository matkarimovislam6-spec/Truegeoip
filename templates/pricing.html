    Frequently Asked Questions

    What's the difference between Database and API?

    The Database is a one-time download for local/offline use with zero latency. The API provides real-time lookups with automatic updates.

    How often is the database updated?

    The database receives weekly updates. As a lifetime customer, you get access to all future updates at no extra cost.

    Can I switch between plans?

    Yes, you can upgrade or downgrade your API plan at any time. Changes take effect on your next billing cycle.

    Do you offer refunds?

    Refunds are generally not available once the service is accessed or used. If you purchased a plan and did not access or use the service in any way, you may request a refund within 14 days (case-by-case). See our No-Refund Policy.

    Is my data reviewed by humans?

    No. True Geo IP is a fully automated platform. IP lookups, intelligence results, and analytics are generated entirely by automated systems. Human review of individual user requests or results does not occur.
